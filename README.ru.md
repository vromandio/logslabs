# Log Slabs

NeoForge-мод для Minecraft 1.21.1, добавляющий плиты из ванильных блоков дерева.

- **Mod ID:** `logslabs`
- **Minecraft:** 1.21.1
- **Загрузчик:** NeoForge
- **Java:** 21
- **Лицензия:** MIT

### О моде

**Log Slabs** добавляет плиты из ванильных блоков дерева, включая брёвна, древесину, обтёсанные брёвна и обтёсанную древесину. Мод задуман как естественное расширение ванильного Minecraft: плиты имеют соответствующие рецепты и ведут себя как деревянные блоки.

### Возможности

- Добавляет плиты из ванильных блоков дерева для всех пород, включая багровый и искажённый стебли.
- Добавляет соответствующие рецепты крафта.
- Поведение деревянных плит: плиты восприимчивы к огню и могут загореться от лавы.
- Log/wood slabs can be stripped with an axe into the corresponding stripped variants.
- Плиты из брёвен/древесины можно стесать топором до соответствующих обтёсанных вариантов.
- Плиты из древесины поддерживают ориентацию и устанавливаются в направлении взгляда игрока.
- Все плиты можно использовать как топливо для печки, кроме багровых и искажённых.
- Добавлен тег `logslabs:log_slab` для всех добавленных плит.

### Установка

1. Установите Minecraft **1.21.1**.
2. Установите **NeoForge 21.1.x**.
3. Поместите `.jar` мода в папку `mods`.
4. Для мультиплеера установите мод **и на клиент, и на сервер**.
