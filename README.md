# Log Slabs

A NeoForge mod for Minecraft 1.21.1 that adds slabs made from vanilla wood blocks.

- **Mod ID:** `logslabs`
- **Minecraft:** 1.21.1
- **Loader:** NeoForge
- **Java:** 21
- **License:** MIT

### About

**Log Slabs** adds slabs for vanilla wood blocks, including log, wood, stripped log and stripped wood variants. The mod is designed to feel like a natural extension of vanilla Minecraft: the slabs have matching recipes and behave like wooden blocks.

### Features

- Adds slabs made from vanilla wood blocks for all vanilla wood types, including crimson and warped stems.
- Adds matching crafting recipes.
- Wooden slab behavior: the slabs are flammable and can catch fire from lava.
- Log/wood slabs can be stripped with an axe into the corresponding stripped variants.
- Wood-type slabs support orientation and are placed according to the player's look direction.
- Slabs can be used as furnace fuel, except crimson and warped slabs.
- Adds the `logslabs:log_slab` tag for all added slabs.

### Installation

1. Install Minecraft **1.21.1**.
2. Install **NeoForge 21.1.x**.
3. Put the mod `.jar` into the `mods` folder.
4. For multiplayer, install the mod on **both the client and the server**.
